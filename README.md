# FinGuru — Hackathon Prototype

A hackathon-era prototype exploring how transaction data could be transformed into a personal spending analysis and financial-insight experience.

## Concept

The idea was to analyse:

- total expenditure
- spending categories
- merchants
- payment timing
- recurring expenses
- potential impulse spending
- opportunities for better budgeting

## Repository contents

The repository contains early HTML prototypes exploring the product concept and presentation.

## Status

**Prototype / archived experiment.**

This repository is kept as part of my development history rather than presented as a production financial application.
